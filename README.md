# Istanbul Park Yeri — Android test surumleri

Bu depo yalniz APK dosyalari ve surum bilgilerini dagitir. Uygulama kaynak kodu bu depoda bulunmaz.

APK dosyalari Releases bolumundedir. Bunlar gelistirme/test surumleridir; fiziksel cihaz kabul testleri tamamlanmis magazaya hazir surumler degildir.

Uygulamayi kaldirmadan, ayni imzali yeni APK dosyasini mevcut uygulamanin uzerine kurabilirsiniz. Kurulumu Android ekranindan siz onaylarsiniz.
